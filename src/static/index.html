Saved packet captures (.pcap, open in Wireshark)
FileRadioSizeSavedAction

A capture holds every advertisement the radio reported, in order, with the time each arrived (the table above is one row per device; the capture keeps every packet). It also holds the scan commands the radio was given, so the capture shows how it was set up. It is the radio's own report (Bluetooth HCI) and not the raw radio signal: Wireshark shows the advertiser's address, RSSI and advertising data, but not the channel number or the CRC. A capture that is still recording can be downloaded; it contains everything up to that moment. Captures stay on the unit until deleted.
